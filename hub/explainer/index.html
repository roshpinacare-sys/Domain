What this page is — read it even without JavaScript

This path is the home of the SAOS animated explainer — “In Plain Words”: nine scenes, about two minutes, zero scary words. It answers, in plain English, what SAOS is and why every claim gets a receipt: people say things about money on the internet, so we photograph the notebook — a custom_json anchor signed onto public blockchains — and the seal goes to Ethereum, Solana and Steem with real explorer links you can open yourself. It also shows what happens when someone tries to edit history, what an anchor costs (measured: $0.0000081), and what honesty looks like when a machine admits mistakes.

The explainer itself is a single static HTML page — inline SVG plus CSS animation, no frameworks — with optional JS only for play/pause and scene navigation; without JS the first scene still renders. Its real on-chain anchors are in the page: an Ethereum tx, a Solana tx and a Steem tx.

Deduplication law (“one generation, one truth”): this index redirects to the single canonical copy at en.html — no parallel versions are kept. The measured books behind everything the explainer claims: saos-live.json · status.json · the receipts book.
