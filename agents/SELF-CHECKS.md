## החוקים (סוללה מבנית — אמת-checkout, דטרמיניסטית, בלי רשת)

| חוק | מה הוא מוכיח | ממצא = |
|---|---|---|
| `R-BALANCE` | כל תגית נפתחת ונסגרת בכל עמוד (parser סטאק; raw-text ל-script/style/title/textarea; void+self-closing מוכרים) | תג לא-סגור, סגירה-יתומה, סגירה שחוצה תגים פתוחים |
| `R-SCRIPT` | כל script פנימי קלאסי (לא module/ld+json/importmap/external) עובר `new Function` | SyntaxError — סקריפט שימות בזמן-ריצה |
| `R-CANONICAL` | canonical מדבר על ה-URL המוגש: `index.html` (שורש/תיקייה) → URL-ספרייה; 404.html פטור; מראה רשאית ל-canonical אל Console (חוק-המראות) | canonical מועתק/מוזר — הבאג-מחלקה של copy-paste head |
| `R-STUB` | גמלת-הפניה בריאה: noindex + יעד refresh קיים בעץ (יחסי נפתר מול תיקיית-ה-stub; ספרייה ← index.html; מרכאות-מעורבות נתמכות) + canonical מוחלט = היעד | הפניה לעמוד-מת (רקבון שקט), סטאב בלי noindex, canonical יחסי |
| `R-SITEMAP` | parity דו-כיווני: כל `<loc>` קיים בעץ; כל עמוד indexable (לא-סטאב, לא-404, בלי noindex) נמצא ב-sitemap.xml | sitemap מפרסם קובץ שאיננו, או עמוד חי נעלם מהמפה |
| `R-TRUTH` | מדדי-האמת הדו-ספריים (R74) בכל דלתות-הכסף: money.html ← `id="sim-saos"` + `R74`; wallet.html ← `id="truth-banner"` + `R74` | אמת שנמחקה בשקט — הרגרסיה החמורה ביותר האפשרית |

ממצא-מבני נכנס ל-`verdict.findings` (עם `rule`+`file`+`note`) → `overall: FAIL` —
**אדום נשאר אדום עד שמתוקן; הקבלה תמיד כנה, exit-code תמיד 0** (ה-verdict נושא את האמת).

## מה נמדד מה-חי (החלק הוותיק)

סריקת קישורים על-פני-השטח הציבורי ב-Pages: כל href/src בכל עמוד-חי. פנימי 404 = FINDING.
חוץ 404 = FINDING. חסימת-בוט חוץ (403/429/502) = רמז בלבד. 429/503 מ-github.com שלנו =
TRANSIENT (ריטרי ×3). קישורי-JS דינמיים אינם נסרקים — הם אינם href סטטי.

## גבולות-האמת (מה הסוללה לא תופסת)

- סקריפטי module עוברים השמטה מכוונת (top-level await תקף שם) — הדפדפן הוא הבודק שלהם.
- קישורים הנבנים בזמן-ריצה מ-JS לא נסרקים כקישורים.
- `R-BALANCE` סלחן לתגיות-לא-סטנדרטיות שהדפדפן סולח עליהן; הוא צד שבירה-מבנית, לא מנוע-HTML5 מלא.
